# WazOS Unified Perchance Generator

This generator is a compact, self-contained Perchance-style UI assembled from the strongest patterns across the WazOS branches.

## Highlights
- Bio-mechanical green CRT / terminal aesthetic
- Biped, lattice, portrait, and robot rig modes
- Prompt builder with negative prompt support
- Pollinations image generation integration
- Includes the unified shell layout and the strongest generator UX ideas from the WazOS branches

## Open locally
Open `unified/index.html` in a browser.

## Notes
The generator is intentionally front-end only and is designed to work as a Perchance-compatible generator page.
